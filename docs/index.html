Keep notebook outputs out of git.

nbripout strips outputs, execution counts and noisy metadata from Jupyter notebooks as you commit. It is a drop-in replacement for nbstripout: same options, same git setup, byte-for-byte the same files. It never leaves a notebook half-written, and it is 10 to 90 times faster.

$ cargo install --git \
https://github.com/thomascamminady/nbripout
$ nbripout --install

Needs Rust 1.81 or newer. Run nbripout --install in each repository, or nbripout --install --global once.

Switching takes one command

Run nbripout --install wherever nbstripout is set up today. nbripout registers under nbstripout's filter name, so committed .gitattributes, filter.nbstripout.extrakeys settings and teammates who stay on nbstripout keep working, and both tools write identical files.

That is tested, not assumed. A differential test runs nbstripout 0.9.1 next to nbripout on 3,000 generated and 208 real-world notebooks with 15 combinations of options and compares every byte, the list of files that would change, and the files left on disk. It finds no differences.

.gitattributes stays as it is

*.ipynb filter=nbstripout
*.zpln filter=nbstripout
*.ipynb diff=ipynb

Your notebook survives a failed write

nbstripout empties a notebook before it writes the stripped version. If anything fails in between, the notebook is gone. A code cell without an outputs key, as some generators and hand edits produce, is enough:

nbstripout 0.9.1

$ nbstripout analysis.ipynb
Traceback (most recent call last):
  ...
AttributeError: outputs
$ wc -c < analysis.ipynb
       0

nbripout

$ nbripout analysis.ipynb
$ wc -c < analysis.ipynb
     314
  • The stripped notebook goes to a temporary file that replaces the original only once it is complete, so a crash, Ctrl-C or a full disk leaves the old version in place.
  • Symlinks stay symlinks and file permissions are kept.
  • Notebooks that need no stripping are not touched, so their timestamps stay put.
  • A broken notebook is reported with a line and column, the remaining files are still stripped, and the exit code is 1.

Fast enough to forget about

Most of nbstripout's time goes into starting Python, once for every notebook git hands it. nbripout starts in milliseconds and, by default, lets git keep one nbripout process running for all notebooks in a command.

nbstripout 0.9.1 nbripout

Median wall time on an Apple M1 Max, with 208 notebooks (70 MB) from three public books. Bars are scaled per row to nbstripout's time. nbstripout has no shared-process mode, so the last row compares against its only setup.

Where it deliberately differs

Byte-for-byte compatibility stops where nbstripout crashes, loses data or behaves randomly.

Situationnbstripout 0.9.1nbripout
--drop-tagged-cells "a b"Drops only cells tagged bDrops cells with any listed tag
--drop-empty-cells on v2 and v3 notebooksDrops every code cellDrops only code cells without code
An error after writing has startedLeaves an empty fileLeaves the file unchanged
--keep-id with missing or duplicate idsNew random ids on every runThe same ids on every run
Zeppelin notebooks through the git filterCrashesDetects and strips them
One broken notebook among manyStops thereStrips the rest, then exits with 1
--install in a linked worktreeWrites an attributes file git ignoresWrites the one git reads

Everyday commands

nbripout --install
Strip notebooks automatically whenever you stage them in this repository.
nbripout --status
Show how the git filter is configured.
nbripout analysis.ipynb
Strip a notebook in place.
nbripout --verify *.ipynb
Exit with 1 if anything would be stripped. Useful in CI.
nbripout --keep-output report.ipynb
Keep outputs but still remove execution counts and metadata. Single cells keep theirs with a keep_output tag.
nbripout --extra-keys "metadata.foo"
Remove more metadata. git config filter.nbstripout.extrakeys makes it permanent.
cat in.ipynb | nbripout > out.ipynb
Strip from standard input to standard output.

Every nbstripout option works the same way; nbripout --help lists them. For pre-commit, use the hook id: nbripout from https://github.com/thomascamminady/nbripout.
